# 🤖 WHG BOT - Zalo Automation

Chào mừng bạn đến với **WHG BOT** - Hệ thống bot Zalo tự động hóa mạnh mẽ, được phát triển bởi **ducanh**.

## 🌟 Chức năng chính
- Tự động quản lý nhóm (duyệt mem, kick, mute).
- Hệ thống game, kinh tế ảo.
- Tương tác AI, tạo QR Code, tải media.
- Chống spam, chống link tự động.

## 🚀 Hướng dẫn cài đặt
1. Cài đặt Node.js (khuyên dùng Termux trên Android).
2. Clone repo này về máy:
   git clone https://github.com/ducanhpq0908-creator/ducanh.git
3. Cài đặt thư viện:
   npm install
4. Cấu hình thông tin Zalo:
   - Copy file `config.example.js` thành `config.js`.
   - Điền IMEI, Cookie, UID Admin của bạn vào `config.js`.
5. Khởi chạy bot:
   node main.js

## ⚠️ Lưu ý bảo mật
- **TUYỆT ĐỐI KHÔNG** commit file `config.js` hoặc `zalo_auth.json` lên GitHub. Hãy để chúng trong `.gitignore`.
- Sử dụng tài khoản Zalo phụ để tránh bị ban.
